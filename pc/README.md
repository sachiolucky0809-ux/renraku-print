# 連絡事項プリント作成（PC版）

`renraku-print-pc.html` を PC にコピーし、ダブルクリックで開くだけで使えます。
インターネット接続は不要です（ファイル1つで完結しています）。

- 対応ブラウザ: Microsoft Edge / Google Chrome / Firefox
- 印刷: プレビュー →「印刷」で通常の印刷画面が開きます（「PDFに保存」も可）
- 下書き: そのPC・そのブラウザ内に保存されます。ブラウザの閲覧データを消去すると消えます。

## 更新方法（開発者向け）

このファイルはスマホ版 `index.html` から自動生成しています。直接編集せず、
`index.html` を修正したあと次を実行してください。

    python3 tools/build-pc.py
